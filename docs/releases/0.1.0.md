# TanaHub 0.1.0 — Preview

First public preview for early testing. Download an installer below; build tools and a .NET runtime installation are not required.

TanaHub brings a new Tauri + Svelte desktop client to the existing .NET anime and manga tracker. It keeps your library in SQLite and reuses the current catalog, recognition and data-exchange services. The existing Avalonia client remains available during migration.

## Included

- Home statistics and recommendations, searchable Library and Discover, full title details, related titles and airing schedules.
- Progress, personal ratings, notes, reviews, tags, custom lists and editable tracking dates with draft confirmation.
- trace.moe and SauceNAO recognition, saved history, AniList import, MAL XML import/export and CSV export.
- Clear first-use actions, labelled compact navigation, keyboard skip link and heading focus, independent collection searches and improved save/error feedback.
- Explicit AniList import confirmation, supported catalog choices and a build-environment doctor for source checkouts.
- Fixes for progress overflow, date preservation, failed-page retries and provider-ID matching.

## Packages

| Platform | Package |
|---|---|
| Apple Silicon macOS 15+ | `TanaHub-0.1.0-osx-arm64.dmg` (or `.app.tar.gz`) |
| Windows x64 | `TanaHub-0.1.0-win-x64.exe` |
| Linux x64 | `TanaHub-0.1.0-linux-x64.deb` or `.AppImage` |

Each platform includes a SHA-256 checksum file. The .NET sidecar is self-contained. Intel macOS and Windows/Linux ARM64 packages are not included.

On macOS, open the DMG and drag TanaHub to Applications. For Linux AppImage downloads, mark the file executable with `chmod +x <asset>.AppImage` before launching it; FUSE 2 is required, or use `--appimage-extract-and-run`. Windows installers may need to download WebView2 if it is absent. See [installation and first-use instructions](https://github.com/Komortes/TanaHub/blob/v0.1.0/docs/getting-started.md), including OS trust warnings.

## Known limits

- macOS packages use an ad-hoc signature and are not notarized. Windows installers are unsigned; OS trust warnings are expected.
- Native macOS app startup, catalog access, tracking dates, rating and persistence have been tested. All three platforms have automated build, .NET and self-contained core checks; Windows/Linux interactive installation and full end-to-end validation are pending.
- Real AniList OAuth, live recognition uploads and native import/export file dialogs need final native checks. Automated tests cover controlled service and UI scenarios.
- AniList support imports your library; it does not continuously sync local changes back. GitHub update checks link to releases; installation is manual.

## Data precautions

Close TanaHub and back up its app-data directory before trying a preview. Use an absolute `TANAHUB_DATA_DIRECTORY` for a separate profile. Avoid editing one profile from Avalonia and Tauri at the same time.

Report reproducible problems with the version/commit, OS, architecture and steps. Remove credentials and personal data from reports. See [the release guide](https://github.com/Komortes/TanaHub/blob/main/docs/release.md) and [smoke checklist](https://github.com/Komortes/TanaHub/blob/main/docs/smoke-test.md).
